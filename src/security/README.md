# `src/security` — طبقات الأمان

مجلد تنظيمي يجمع طبقات الأمان في مكان واحد. لا يحتوي الشيفرة الحالية أي
استيرادات من هذا المجلد — الأعمدة شاغرة لتُملأ تدريجياً دون التأثير على
باقي التطبيق.

| المجلد | المسؤولية |
|---|---|
| `auth/` | تدفّقات المصادقة والجلسات والرموز |
| `validation/` | التحقق من صحة المدخلات قبل الإرسال |
| `encryption/` | التشفير وفكّ التشفير وحفظ الأسرار |
| `headers/` | ترويسات الأمان (CSP، HSTS، إلخ) |
| `sanitization/` | تنقية HTML/المستخدم (يرتبط بـ `src/utils/sanitize.js`) |
| `guards/` | حرّاس المسارات والصلاحيات |

> عند إضافة شيفرة هنا اربطها عبر alias `@` (`@/security/...`)، وأبقِ الطبقات
> نقية وقابلة للاختبار في Node دون الاعتماد على المتصفح.
